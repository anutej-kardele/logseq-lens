# Logseq Lens 1.0.1

A small fix release. Install it over 1.0.0: your notes, Scratchpad, flashcard progress and GitHub connection are kept.

## Fixes
- **Clearer sync errors for duplicated pages.** If an export lists the same page twice, the message now names both
  pages, their kinds and the shared UUID (instead of only "duplicate page uuid at page #N"). Your existing notes are
  still kept when this happens.
- **Pages without a title are no longer rejected.** A page with a valid UUID but no title is imported as
  "Untitled page (xxxxxxxx)", with its blocks intact, instead of failing the whole sync.

## If you saw "duplicate page uuid" after updating your backup
This comes from the export, not the app: a class/tag page that has content was exported as a second page with
the same UUID. The export script (`scripts/edn_to_json.py` from
[logseq-backup-blueprint](https://github.com/anutej-kardele/logseq-backup-blueprint)) needs the fix that attaches a
class page's content to the class instead; after updating it, run the backup again and tap sync.
