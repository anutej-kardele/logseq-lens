# Logseq Lens 1.0.0

The first public release: an unofficial, read-only Android companion for Logseq DB graphs.

## Highlights
- **Read** journals and pages with nested outlines, Markdown, code blocks, links, tags and backlinks.
- **Offline search** across all notes, with jump-to-block.
- **Flashcards** from blocks tagged `#Card`, grouped by your other tags, with Know / Again review and local progress.
- **Scratchpad**: one local note with checkboxes, editable on Home and from a **home-screen widget**.
- **GitHub sync**: paste your private backup repo's link and a read-only token. Switch between exports from the
  graph name.
- Light, dark and system themes.

## Requirements
- Android 8.0 or newer.
- A Logseq DB-version graph exported with [logseq-backup-tool](https://github.com/anutej-kardele/logseq-backup-tool)
  to your own private GitHub repo, and a fine-grained token with **Contents: Read-only**.
